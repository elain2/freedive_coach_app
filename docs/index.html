자주 묻는 질문

Q. 음성 로그 기능은 어떻게 사용하나요?

홈 화면에서 '새 로그'를 탭하고 마이크 버튼을 누른 후 다이빙 내용을 말씀하세요. AI가 자동으로 정리해 드립니다.

Q. 영상 분석은 어떤 영상이 좋나요?

측면에서 촬영한 영상이 가장 정확한 분석 결과를 제공합니다. 전신이 보이도록 촬영해 주세요.

Q. 오프라인에서도 사용 가능한가요?

호흡 훈련과 다이빙 시뮬레이션은 오프라인에서 사용 가능합니다. AI 기능(음성 로그, 영상 분석)은 인터넷 연결이 필요합니다.

Q. 데이터는 어디에 저장되나요?

모든 데이터는 기기에 안전하게 저장됩니다.
